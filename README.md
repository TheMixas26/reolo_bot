# Предложка Империи

Telegram/VK-система для канала [Имперский Вестник](https://t.me/reolo_channel) и связанных сервисов.

Проект уже давно вышел за рамки обычной предложки. Сейчас в репозитории живут:

- модерация пользовательских постов, альбомов, вопросов и личных сообщений администратору;
- публикация в Telegram-канал и опционально на стену VK;
- черновики и отложенные публикации;
- достижения, профиль пользователя и счётчик активности;
- дни рождения, погодные уведомления и имперский календарь;
- отдельный банковый бот;
- отдельный RPG-бот с карточной мини-игрой и дуэлями;
- интеграция с YandexGPT по тегу `#ai`.

## Быстрый старт

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Отредактируйте `dev/settings.py` для названий ботов, валюты и других публичных параметров.

3. Создайте `dev/config.py` со своими токенами, ID чатов и секретами.

4. Запускайте проект из корня репозитория:

```bash
python dev/main.py
```

При старте `dev/main.py` сначала запускает `pytest tests/ -v`. Если тесты не проходят, боты не стартуют.

## Что важно знать

- Основная SQLite-база хранится в `dev/database/bot.sqlite3`.
- Отложенные публикации хранятся отдельно в `dev/database/scheduled_posts.json`.
- Фоновые задачи регистрируются плагинами через общий `APScheduler`.
- Основной, банковый и RPG-боты запускаются в отдельных потоках.
- VK-адаптер подключается только при наличии `VK_TOKEN` и `VK_OWNER_ID` или `VK_GROUP_ID`.
- Несекретные настройки проекта вынесены в `dev/settings.py`.

Если нужен подробный шаблон `config.py` и описание модулей, смотрите [документацию по настройке](doc/ru/setup.md) и [архитектуре](doc/ru/architecture.md).
